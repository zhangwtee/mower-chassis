# 上机清单

> 首次上机按这个顺序走，别跳步。

## 阶段 0：上电之前（不接线）

- [ ] Keil Rebuild 是 **0 error 0 warning**
- [ ] `OBJ/mower.hex` 正常生成
- [ ] 烧录器、电源、急停开关都在手边
- [ ] **刀片动力线断开**（第一次上电绝对不要接刀片）

## 阶段 1：只上电，不接电机

- [ ] 板子能起来，不反复复位（如果有 LED，能看到心跳）
- [ ] 挂调试器能看到 `chassis` / `telem` / `imu` / `hmi` 四个任务在跑
- [ ] 万用表量 3.3 V / 5 V 正常

## 阶段 1.5：开机自检（接电机，车放地上）

开机自检会让车前后各走约 0.6 秒、原地转 0.6 秒。**车要放在地面上，周围留空，刀片动力线仍断开。**

- [ ] 上电后 10 秒内车不动
- [ ] 10 秒后车开始前后动，动作顺序与文档一致
- [ ] 自检通过后进入可控制状态（约 14.2 秒；上位机那边按 15 秒等）
- [ ] 故意把编码器线拔掉一路再上电：应进 `FAULT`，之后发速度帧**不动**
- [ ] 把 `SELFTEST_ON_BOOT` 改成 0 再编译：上电 10 秒后直接就绪，不动作

## 阶段 2：串口

- [ ] UART3 接 USB-TTL 到 PC，115200，能看到 20 Hz 的 24 字节帧
- [ ] 帧头帧尾对、BCC 对（用上位机的 `bridge/test/test_protocol.py` 的解析器验）
- [ ] 电压字段与实际电池电压一致（差 < 0.2 V）
- [ ] 上电 10 秒内发下行帧无反应，10 秒后发速度帧有反应 —— **这条是确认静默期行为**

## 阶段 2.5：IMU

- [ ] 上电后 10 秒内保持静止，让零偏采样完成
- [ ] 串口解析上行帧，z 轴加速度约等于 1 g（约 1671，静止平放）
- [ ] 把车往左倾，y 轴加速度变化，方向与倾斜一致
- [ ] 静止时角速度三轴接近 0（零偏补偿后应小于几十个 LSB）
- [ ] 转一下车，角速度符号与实际转向一致
- [ ] 拔掉 IMU 再上电：不应死机，遥测里加速度角速度保持 0
## 阶段 2.2：栈水位（跑够 1 分钟再看）

- [ ] 长按用户按键切到第二页，四个数字都要读出来
- [ ] `CH` 应明显小于 512，`TE`/`IM`/`HM` 应明显小于 384
- [ ] **任何一个小于分配量的四分之一**（chassis < 128，其余 < 96）→ 记下来，加大那个任务的栈
- [ ] 把这四个数记进 `docs/上机清单.md` 末尾的实测记录，别靠记忆

水位是"历史最低剩余"，不是当前值。所以要让所有路径都跑一遍（自检、急停、CAN 收发、
写 Flash）之后再读，才有意义。

## 阶段 2.3：用户按键（PC5）


- [ ] 待命状态下双击 → IMU 重新采零偏（10 秒内保持静止）
- [ ] 重标定期间陀螺读数不跳变（沿用旧零偏，采完才换新的）
- [ ] 运行中（RUN）双击 → **不触发**重标定
- [ ] 轻碰一下按键（< 30 ms）→ 不算单击，不触发任何动作

## 阶段 2.4：声光

- [ ] 上电瞬间灯是白色
- [ ] 自检期间黄灯闪、蜂鸣一声
- [ ] 进待命变绿；若自检是从自检跑到待命，应有两声短鸣
- [ ] 按住使能开关发速度进 RUN，灯变青
- [ ] 急停：紫灯闪 + 一声短鸣
- [ ] 人为让自检失败（拔一个编码器），红灯常亮 + 三声短鸣，之后每 3 秒响一声
- [ ] 灯是高电平有效；如果实机是反的，把 `bsp/led.h` 的 `LED_ACTIVE_LOW` 改成 1
- [ ] **如果蜂鸣器是反的**（该响的时候不响），把 `bsp/buzzer.h` 的 `BUZZER_ON_LEVEL` 改成 0

## 阶段 2.6：OLED


- [ ] 上电能看到四行:状态、IMU、电压、轮速、失能标志
- [ ] 电压那一行与实际电池电压一致(差 < 0.2 V)
- [ ] 用手转轮子,轮速那行有变化,正负与转向一致
- [ ] 按使能开关,`FS` 从 0 变 1
- [ ] 界面不闪、不花屏（OLED 是四线 SPI：PD7=SCL、PD6=SDA、PD5=RES、PD4=DC）
## 阶段 3：电机（一次只接一个轮子）

- [ ] 只接 A 轮，悬空：发 Vx=+0.2，轮子**向前**转
- [ ] 编码器读数为正，且量级与 0.2 m/s 相符（误差 < 20%）
- [ ] 发 Vx=-0.2，反向、读数为负
- [ ] 从 0 直接发 Vx=0.5：轮子应是**渐进加速**到目标，不是一下窜到位（平滑生效）
- [ ] 发 Vx=10（超限）：实际只到 3.5 m/s 附近（限幅生效）
- [ ] **转向反了就改 `bsp/motor.h` 的 `MOTOR_A_SIGN` / `MOTOR_B_SIGN`，不要改业务代码**
- [ ] A 轮确认完再接 B 轮，重复上面四条
- [ ] 两个轮子都接上，发 Vz=+0.5：车应该**原地左转**（还是右转取决于约定，记录实际值）

## 阶段 4：安全

- [ ] 切到诊断第三页，确认 `AGE` 在随指令递增：正常收到 20 Hz 指令时它应该在 0~50 之间跳
- [ ] 运行中拔掉 UART3 线 → **`AGE` 一路涨到 500 然后车停**（不是等到 2 秒）
- [ ] 运行中按急停开关 → 立刻停车，且**松手后不会自己恢复**
- [ ] 运行中把电池电压调低到 20 V 以下 → 停车
- [ ] **电压回到 20.5 V → 仍停着**（滞回锁住）；升到 21 V 以上才恢复
- [ ] 运行中按下使能开关（PE4 拉低）→ 停车；松开应恢复（使能开关不锁存）
- [ ] 串口看到的 `FlagStop` 在使能开关按下时应为 1
- [ ] 发 CMD=7 → 停车并锁存；再发 CMD=0 → **不动**；发 CMD=8 → 可以再动
- [ ] **使能开关按下去之后再发 CMD=8** → 解除不生效，上位机 0.6 s 后会报 `still_latched` 并提示检查开关（固件的解除要求开关在位）
- [ ] 以上每条都试一遍"锁存期间发速度帧"，确认不动
- [ ] **斜坡保持**：把车停在斜坡上进 IDLE（发 0 速度），观察是否溜车；应基本不溜
- [ ] **平地静止 5 秒后**：电机电流声应消失（驻车释放生效）
- [ ] **斜坡上静止**：电流声应一直有，车不溜（斜坡不释放）
- [ ] 释放后再推一下车：应立刻恢复闭环，推动时有阻力
- [ ] 拔掉 IMU 再试：应**永不释放**（宁可有声也不溜车）

## 阶段 5：舵机

**先架空**。自检会扫 500~2500，如果实车行程比这小，
先松开连杆再上电，别让它顶死。

- [ ] 自检时舵机平滑从左到右再回中，没有卡顿、没有异响（每拍 20 µs，2 秒扫完）
- [ ] 扫到两端（500 / 2500）时舵机不堵转、不发烫；若顶死，把 `app/chassis.c` 的
      `SERVO_LOW` / `SERVO_HIGH` 收窄，别改协议侧的 500~2500 夹紧
- [ ] 发 CMD=4，脉宽 1500 → 舵机在中位
- [ ] 发 0 和 65535 → 确认被夹到 500/2500（这是固件侧的限幅，不是上位机做的）

## 阶段 5.5：蓝牙 APP（UART4，9600）

- [ ] 蓝牙连上，按 W → 刀片继电器吸合
- [ ] 再按 V 或 P → 刀片断开
- [ ] 刀片开着的时候按使能开关 → 刀片立刻断，且松开开关后**不会自己恢复**
- [ ] 刀片开着的时候断开蓝牙 → **刀片不会停**（这是设计取舍，靠物理开关兜底）
- [ ] 按 S → 进自检（前提是车已停稳）
- [ ] 摇杆八个方向都试一遍，方向与图上一致
- [ ] 摇杆**松开**后车应停（APP 交回上位机）
- [ ] 按 X/Y 改速度基准，摇杆最快速度跟着变
- [ ] **蓝牙断线时车不应误触发自检**（`+DISC:SUCCESS` 里含 S，靠状态串过滤挡住）

## 阶段 6：刀片（最后，且必须有人守着）


- [ ] 接刀片动力线，车架空，**周围清空**
- [ ] 发刀片开启命令 → 继电器吸合，刀片转
- [ ] **停发刷新 → 300 ms 内刀片停**（`SAFETY_BLADE_AGE_MAX` 判定）
- [ ] 刀片转的状态下按急停开关 → 刀片停
- [ ] 刀片转的状态下断串口 → 刀片停
- [ ] 刀片转的状态下把电压调低 → 刀片停

## 阶段 7：看门狗（默认关闭，验证后打开）

- [ ] 把 `USE_IWDG` 改成 1，重新编译烧录
- [ ] 正常运行 10 分钟不复位
- [ ] 在调试器里人为让 `chassis` 任务卡死 → 2 秒内复位
- [ ] 确认 `bsp/flash.c` 擦除期间不会饿死看门狗（擦 16 KB 约 250 ms）

## 阶段 8：超声波

- [ ] 超声波板接 CAN，用 USB-CAN 或另一块板确认它发 `0x101`/`0x102`
- [ ] 抓 19 字节超声波帧（头 0xFA），A~F 六路有值，G/H 恒 0
- [ ] 手挡探头，数值跟着变
- [ ] 确认本固件的 `0x201`~`0x203` 与板子的 `0x101`/`0x102` 同时存在、互不干扰

---

## 出问题先看哪里

| 现象 | 先查 |
|---|---|
| 车不动，串口有帧 | 上电 10 秒静默期过了吗；`FlagStop` 是不是 1 |
| 车不动，串口没帧 | 任务是不是没起来；串口波特率/引脚 |
| 轮子转向反 | `bsp/motor.h` 的 `MOTOR_A_SIGN` / `MOTOR_B_SIGN` 取反 |
| 编码器读数为负 | `bsp/encoder.h` 的 `ENCODER_L_SIGN` / `ENCODER_R_SIGN` 取反 |
| 停止距离太远 | 指令超时阈值（500 ms）乘以当前速度 |
| 反复复位 | 先关 `USE_IWDG` 再查 |
